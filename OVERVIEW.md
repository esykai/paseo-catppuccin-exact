# Catppuccin Exact

Catppuccin Mocha and Latte for Paseo. The dark theme uses `#1e1e2e` for the workspace and `#181825` for sidebars; the light theme uses `#eff1f5` and `#e6e9ef`, with `#7130c7` as the accent. Paseo derives plugin-theme sidebars from the workspace color, so the client overrides the web sidebar variable to keep them darker; native clients keep Paseo's derived color. Choose either under Settings, Appearance. Both are palette data only: the plugin reads no files, sends nothing, and contributes no screens, commands, or settings.
